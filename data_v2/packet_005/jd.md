# Backend / Platform Engineer — Enterprise — scale and governance

## Context
Large engineering organization with defined interfaces, reliability targets, compliance controls, and cross-team delivery.

## Must-have evidence
- production API or service ownership
- Python, Go, or Java
- distributed systems fundamentals
- production reliability
- cross-team execution
- change management

## Preferred evidence
- observability
- event-driven systems
- cloud cost awareness
- regulated systems
- incident leadership
- architecture governance

## Interview focus
- What evidence supports sustained ownership at organizational scale?
- Which claims are firsthand and which describe team outcomes?
